## Приёмка

- В изолированном Linux прошли `go test ./...`, повторный полный `go test -race`, `go vet ./...`, проверка синтаксиса WebUI и скрипта службы. Первый прогон с -race исчерпал дедлайн теста отката на финальной проверке статуса службы. Отдельный повтор этого теста и полный повтор завершились успешно.
- Браузер проверил все три страницы при 1920×1080 и 375×667. Сквозной тест через Go API подтвердил отмену и выполнение массового удаления с сохранением активной записи и подписки.
- HTTPS-подписки проверены с текстом, Base64 с переносами строк, подтверждённым пустым списком и повреждёнными ответами. Проверены ручные и общие записи, переход по порядку и сохранность состояния.
- Перебраны 4 860 сочетаний параметров VLESS. Отдельно проверены 47 конфигураций официальным Xray 26.11.9. Тест с живым локальным VLESS-трафиком подтвердил восстановление после сбоя, готовность к завершению обновления после ответа через SOCKS и завершение дочернего Xray после SIGKILL демона. [Матрица VLESS](VLESS-MATRIX.md)
- Проверены откат, неверный SHA-256, подпись на тестовом ключе, защита чужого интерфейса, повтор очистки и доставка статистики с локальным HTTPS-приёмником.
- На физическом Keenetic ARM64 проверены установка, порт 8080, внешний HTTPS, вход и вывод всех трёх страниц. Установка для приёмки использовала изолированный RAM-стенд. Для ARMv7, MIPSEL и MIPS подтверждены сборки. Официальные MIPS/MIPSEL-архивы Xray требуют hardfloat. [Совместимость Xray](INSTALL-GO.md#совместимость-ядра-на-mips)
