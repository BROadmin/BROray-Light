# BROray-Light — практическая инструкция

Эта памятка дополняет полное руководство в корневом `README.md` и предназначена для быстрой самостоятельной установки и эксплуатации Stable `1.0.0-r2`.

## Быстрый путь

1. Убедитесь, что на Keenetic установлен Entware для `aarch64-3.10`, есть SSH-доступ `root`, интернет и не менее 100 МБ в `/opt`.
2. Убедитесь, что полный BROray отсутствует: `test ! -e /opt/broray && test ! -e /opt/etc/init.d/S24broray`.
3. Загрузите `SHA256SUMS` и `broray-light-install-1.0.0-r2.sh` из релиза `v1.0.0-r2`, проверьте установщик и выполните его через `/opt/bin/ash`.
4. Откройте `http://IP-KEENETIC:8080/` или опубликованный адрес `https://brolight.ИМЯ.keenetic.link/`.
5. Войдите логином и паролем Keenetic.
6. Добавьте подписку с понятным именем либо одну VLESS-ссылку, проверьте и активируйте сервер.
7. На Главной настройте интерфейс Keenetic и убедитесь, что соединение работает.

Точные команды установки, описание всех кнопок, статусов, обновлений, диагностики, резервного копирования и удаления находятся в [полном руководстве](../README.md).

## Ежедневная работа

- **Главная** показывает активный сервер, соединение, автопереключение, интерфейс Keenetic, Xray и Stable-версию Light.
- **Серверы** добавляет только VLESS, проверяет и активирует узлы, меняет порядок и управляет автопереключением.
- **Подписки** присваивает имя, импортирует только VLESS, обновляет вручную или по расписанию и удаляет подписку вместе с её неактивными серверами.

Дубли VLESS устраняются автоматически. Активный сервер всегда сохраняется. Активный сервер или подписку, которой он принадлежит, удалить нельзя — сначала активируйте другой узел.

## Контроль состояния

```sh
/opt/etc/init.d/S23broray-light-updater status && echo "Updater: OK"
/opt/etc/init.d/S24broray-light status && echo "BROray-Light: OK"
/opt/broray-light/runtime/xray version
/opt/bin/broray-light-updaterctl check
/opt/bin/broray-light-web-publishctl status
```
