На повторную аппаратную проверку маршрутом `openrouter/baidu/ernie-5.5-flash-preview:free` вызвана модель `baidu/ernie-5.5-flash-preview:free`, execution_id `a0eb96b7-ea12-46d3-827f-f351b442146a`. Ответ оборвался на разборе условия проверки каталога. Изменения кода по этому ответу не внесены. Для диагноза собран отдельный hook, который проверяет эффективный UID, владельца, тип, режим и результат разрешения пути штатного каталога Entware.

Рекомендация считать этот вызов достаточной проверкой симлинка отклонена: переход в каталог может разрешить симлинк. Сохраняются явные проверки ссылок и отдельная регрессия.

Изоляция аппаратной приёмки: `gemini-3.5-flash-lite` → `google/gemini-3.5-flash-lite`, execution_id `c3ebdc4c-46f3-422b-ae5d-83a3e429abc2`. Сохранена проверка владельца каталога запуска. Приёмка установщика перенесена в приватное дерево `/tmp` того же устройства. Реальные UID, пути и режимы подтверждены журналом устройства, а сценарий не меняет прав общего тома.

GPT-6.2 Sol адаптировал проверку каталога под `stat -t` и запуск службы под POSIX shell без `nohup`. Отсутствие обеих возможностей было зафиксировано на KN-3812.
