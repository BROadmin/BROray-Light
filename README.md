# BROray-Light 3.5.10

Отдельный менеджер Xray для Keenetic и Netcraze с WebUI внутри Go-бинарника. Главная управляет подключением, резервным переключением, интерфейсом Keenetic и обновлениями. На страницах «Серверы» и «Подписки» можно импортировать профили, проверять подключение и упорядочивать серверы.

- [Установка и переход с Light 1.x/2.0](docs/INSTALL-GO.md)
- [Закреплённый донор и таблица переноса](docs/UPSTREAM-GO.md)
- [Журнал FreeLLMAPI](docs/PROVIDER-WORKLOG.md)
- [Сборки, проверки и ограничения](docs/VALIDATION-GO.md)
- [История предыдущих выпусков Light](CHANGELOG.md)

Приложение и Xray устанавливаются отдельно. Руководство для Go-версии относится к локальной сборке 3.5.10. GPL-3.0 и лицензии компонентов включены в архив.
