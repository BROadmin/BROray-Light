# Происхождение BROray-Light 3.5.10

26.11.2026 GitHub Releases API вернул BROray `v3.5.10`, `draft=false`, `prerelease=false`, опубликовано 10:53:49 UTC. Сайт проекта указывал Stable r15. `git ls-remote` и локальный detached checkout подтвердили полный SHA `92dc010ebad5fd21dff9e625925e9847b3714640`. Код брали из этого дерева. Номер Light задан независимо от константы `internal/app.Version` в исходном дереве донора, где осталось значение 3.5.9. [GitHub Release](https://github.com/BROadmin/BROray/releases/tag/v3.5.10) · [GitHub Releases API](https://api.github.com/repos/BROadmin/BROray/releases/latest) · [Руководство проекта](https://docs.brovibe.cloud/broray/releases/3.5.10/) · [Дерево донора](https://github.com/BROadmin/BROray/tree/92dc010ebad5fd21dff9e625925e9847b3714640)

Ветка Light основана на опубликованном `main` `cf6217f2fdd5f0b55f80211c29f13db28abb42bd`. Рабочее дерево со старыми правками изолировано. Коммит `f6ac953ba6bc4602fbefaf3a758eab28e123e98e` и ветка `feat/go-3.5.0` не обнаружились в оригинальном репозитории на ПК, доступных рабочих деревьях Codex, архиве и удалённых refs. GitHub для запроса коммита вернул `No commit found for SHA`. Сценарии прежней shell-версии остаются в её истории и документации. Это новый Go-порт с отдельными регрессионными тестами.

| Механизм | Решение |
| --- | --- |
| Native-вход Keenetic и права NDW4 | Перенесены проверка `internal/keenetic/auth.go`, права пользователей и тесты. Сессионное хранилище донора использует cookie `BRORAY_LIGHT_SESSION` и CSRF. |
| Атомарная запись, сериализация | Схема записи из `internal/platform/fs.go`: временный файл, sync, rename, sync каталога. Общий mutex защищает состояние и runtime, flock защищает единственный демон и отдельно установщик. |
| Xray и восстановление | Перенесены проверка конфигурации, parent-death на закреплённом OS thread и управление группой процесса из `modules/xray/xray.go`. Контрольный GET идёт через SOCKS. Временный сбой запуска оставляет выбор на диске и допускает повтор. |
| Подписки и активный профиль | Light уже имел защиту от дублей в shell. Go-порт использует точный ключ профиля и сопоставление однозначной ротации параметров по мотивам `areas/subscriptions/remap.go`. Успешная смена SNI/Short ID сохраняет ID и работающий Xray. Подтверждённое исчезновение последнего источника снимает активный профиль. |
| Пауза при сбое WAN | Адаптирована проверка `internal/keenetic/internet_status.go` из r15. При подтверждённом отсутствии WAN сбрасывается счётчик, очередь серверов не расходуется. Независимо от порядка добавления источников применяется пользовательский порядок. |
| Keenetic, владение и очистка | Только собственный native proxy. Сверка running/startup, сохранение квитанции владения при прерывании, отказ при чужих настройках или ссылках и при наличии полного BROray. |
| Удалённый WebUI | Из `areas/keenetic/web.go` перенесена управляемая публикация через HTTPS KeenDNS/CrazeDNS. Light использует отдельное имя `brolight`, управляет правилом после явного подтверждения и подтверждает владение по собственной записи. |
| Установка и обновление | Отдельный Light manifest и ключ, HTTPS, SHA-256 и проверка архива, запись транзакции, откат. Приватная проверка ждёт нужную версию процесса, HTTP через активный SOCKS и подтверждение интерфейса при управлении им. |
| Ядро Xray | Пин `26.11.9` и SHA-256 архивов XTLS перенесены из `modules/xray/xray.go` и сверены с GitHub. Скачивание в runtime, проверка ELF и версии, проба кандидата и сохранение предыдущего бинарника до подтверждения. |
| Парсеры | Перенесены share-links из `modules/servers`: VLESS, VMess, Trojan, Shadowsocks, Hysteria2. Подписки принимают текстовый или Base64-список. Расширенные native JSON и Clash YAML парсеры полного продукта не вошли в эту сборку. |
| Границы Light | Сохранены три страницы, ручной порядок, просмотр, проверка, активация, исключение, удаление и переименование. Исключены Routes, управление DoT, geo-базы, Premium, мастер первой настройки, рейтинги, история качества, сложный редактор и статистика установки. |

Донорские Apache/BSD лицензии зависимостей сохранены вместе с исходниками. В закреплённом дереве донора нет корневого `LICENSE`. Полный репозиторий объявляет GPL-3.0 на основной ветке. В архив Light входит GPL-3.0 из исходного репозитория Light и лицензии использованных компонентов. ## Отдельное ядро Xray

Выбрано `26.11.9`. Все четыре ZIP скачаны и проверены по SHA-256 из закреплённого кода и метаданным GitHub. Размер бинарника взят из проверенного ZIP. Архив Light содержит только приложение и лицензионные материалы. [Выпуск Xray](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9)

| Архитектура | Xray, байт | ZIP Xray, байт |
| --- | ---: | ---: |
| ARM64 | 32 964 732 | 15 231 921 |
| ARMv7 | 34 537 596 | 15 967 355 |
| MIPSEL | 34 668 699 | 24 722 238 |
| MIPS | 34 668 699 | 24 865 673 |

В Light 2.0 уже были три страницы, VLESS, подписки, исключения, резервирование, native-вход, управляемый интерфейс и подписанное обновление. Ветка Go сохраняет эти возможности через новые daemon/WebUI и отдельную схему состояния. Конфигурация shell-выпуска переносится по инструкции установки вручную.

Для Xray файлы проверены и отдельно проанализированы командой `go version -m`. Все четыре официальных ELF-среза собраны с `CGO_ENABLED=0`. Для MIPS и MIPSEL ядро использует `hardfloat`, приложение Light — `softfloat`.
