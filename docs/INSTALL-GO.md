# Установка BROray-Light 3.5.10 по шагам

Откройте терминал Entware, вставьте готовую команду и зайдите в BROray-Light. Команда сама выберет архив для вашего роутера, проверит его и запустит установку.

- **Устанавливаете впервые** — начните с [подготовки роутера](#1-подготовьте-роутер).
- **Терминал Entware открыт, curl уже работает** — переходите к [команде установки](#install).
- **Установлен Light 1.x или 2.0** — сначала сохраните данные и выполните [переход со старой версии](#переход-с-shell-light-1x20).
- **Установлен Light на Go** — используйте [обновление через WebUI](#обновления-и-восстановление).

## 1. Подготовьте роутер

1. Убедитесь, что работают интернет и основная панель роутера. Если возможно, выполняйте установку из домашней сети.
2. В панели Keenetic или Netcraze откройте **Управление → Настройки системы → Изменить набор компонентов**. Для Entware нужна **Поддержка открытых пакетов (OPKG)**. Для управляемого прокси-интерфейса нужен **Клиент прокси**, для внешнего доступа к WebUI — **KeenDNS / CrazeDNS** и зарегистрированный домен роутера.
3. Если **Менеджер пакетов OPKG** уже работает с подключённым накопителем, используйте его. Если Entware ещё нет, установите его по инструкции производителя для своего роутера. При подготовке нового накопителя заранее сохраните нужные файлы. [Установка Entware на Keenetic](https://support.keenetic.com/hero/kn-1012/en/20980-installing-the-entware-repository-on-a-usb-drive.html)

Изменение компонентов может перезагрузить роутер. Дождитесь возвращения панели. Для установки Light достаточно готового Entware. Go на роутер устанавливать не нужно.

## 2. Откройте терминал Entware

Выберите браузер или SSH. Команды следующих шагов вводите, когда в терминале появилась строка с `#`.

### Вариант А. Терминал в браузере

1. Войдите в панель роутера как администратор. Можно использовать её адрес KeenDNS или CrazeDNS.
2. В списке компонентов включите **Интерфейс командной строки в браузере**, если его ещё нет.
3. На странице **Менеджер пакетов OPKG** включите **Доступ** для своей учётной записи администратора и сохраните.
4. Нажмите шестерёнку вверху панели и выберите **Интерфейс командной строки**. Если открылась строка `(config)>`, выполните команду ниже.

```sh
exec sh
```

Если снова видите `(config)>`, проверьте доступ в OPKG и готовность Entware перед продолжением.

### Вариант Б. SSH из домашней сети

В PuTTY, Termius или другом SSH-клиенте укажите локальный IP роутера, например `192.168.1.1`. Войдите как `root` с паролем **Entware** на порту, который настраивали для Entware. Это часто `222` или `22`. При вводе пароля символы могут не отображаться.

Если у вас есть только внешний адрес панели роутера, выберите веб-терминал. Для входа в сам BROray-Light дальше понадобится учётная запись **роутера**.

## 3. Установите curl и сертификаты

Если `curl` уже установлен и загрузки HTTPS работают, переходите к шагу 4. Иначе скопируйте команду, вставьте её в терминал и нажмите Enter.

```sh
opkg update && opkg install ca-bundle ca-certificates curl
```

Дождитесь возврата строки с `#`. Если `opkg` сообщает об ошибке, сначала проверьте, что открыт терминал Entware и роутер подключён к интернету.

## 4. Установите BROray-Light

Скопируйте **весь блок** кнопкой копирования, вставьте в тот же терминал и нажмите Enter. Вставлять свои значения в команду не нужно.

```sh
(
  set -eu
  fail() { printf '%s\n' "$*" >&2; exit 1; }
  [ "$(id -u)" = 0 ] || fail 'Откройте терминал Entware с правами root.'
  command -v opkg >/dev/null || fail 'Команда opkg не найдена. Проверьте, что открыт терминал Entware.'
  command -v curl >/dev/null || fail 'Сначала выполните шаг «Установите curl и сертификаты».'

  arches=$(opkg print-architecture) || fail 'Не удалось узнать архитектуру Entware.'
  arch=$(printf '%s\n' "$arches" | awk '$1 == "arch" && $2 != "" && $2 != "all" && $2 != "noarch" && !seen[$2]++ { print $2 }')
  case "$arch" in
    aarch64-3.10)
      target=arm64
      archive_sha=856a466500e70ab14e473d36588c53b3f6f7c3678b750954367604f82e547e8a
      binary_sha=188e14c7b7e019d8a224844f59e4ed7e250cf16331d40ad8f8f3dc616c398223 ;;
    armv7-3.2)
      target=armv7
      archive_sha=8de7e19d5cfc1bdd90d7500785171424bcd97e5f0ae39268b9fda236c04a7828
      binary_sha=44f254003872820a60b8da37f7a94834fa2aaa271648078f5211f2bde6588d6c ;;
    mipsel-3.4)
      target=mipsel
      archive_sha=ea63eb3a81bd80383aa7fb7a50788868d0bc86a4771cfc49240bdd6ab0705bd5
      binary_sha=0fe5af0cddcf2de15f5bff49c13e0eb20cd9e94686d3ee5a02d1821de1180a47 ;;
    mips-3.4)
      target=mips
      archive_sha=d05fafe85c71539683876abbb0461ab44fb90539def2eaab3e789ebe5da38348
      binary_sha=a0371f4d0fb04cbcf40ffad7aa6c7a15de9cf94f62b62b78052fa92e41a70037 ;;
    *) fail 'Не удалось выбрать архив. Выполните opkg print-architecture и сверьтесь с таблицей совместимости.' ;;
  esac

  work=$(mktemp -d /tmp/broray-light-install.XXXXXX) || fail 'Не удалось создать временный каталог в /tmp.'
  trap 'rm -f "$work/release.tar.gz" "$work/broray-light"; rmdir "$work"' 0
  trap 'exit 1' HUP INT TERM
  base=https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10
  printf 'Скачиваем BROray-Light 3.5.10 для %s…\n' "$target"
  curl -q -fsSL --proto '=https' --proto-redir '=https' --connect-timeout 10 --max-time 120 \
    -o "$work/release.tar.gz" "$base/broray-light-3.5.10-linux-$target.tar.gz" ||
    fail 'Не удалось скачать архив. Проверьте интернет и время на роутере.'
  printf '%s  %s\n' "$archive_sha" "$work/release.tar.gz" | sha256sum -c - ||
    fail 'Контрольная сумма архива не совпала. Скачанный файл удалён.'
  tar -xzf "$work/release.tar.gz" -C "$work" broray-light ||
    fail 'Не удалось извлечь установщик. Проверьте свободное место в /tmp.'
  printf '%s  %s\n' "$binary_sha" "$work/broray-light" | sha256sum -c - ||
    fail 'Контрольная сумма установщика не совпала.'
  "$work/broray-light" install --sha256 "$binary_sha" ||
    fail 'Установщик завершился с ошибкой. Посмотрите сообщение выше.'
  printf '%s\n' 'BROray-Light 3.5.10 установлен. Откройте интерфейс на порту 8080.'
)
```

## 5. Дождитесь результата

Дождитесь сообщения **«BROray-Light 3.5.10 установлен»**. Если команда остановилась, посмотрите последнюю строку в терминале. При ошибке загрузки проверьте интернет и время роутера. При сообщении `unsafe directory /opt/etc/init.d` проверьте, что накопитель Entware принадлежит администратору и защищён от записи посторонними. [Решение проблем на сайте](https://docs.brovibe.cloud/broray-light/troubleshooting/)

## 6. Откройте WebUI и подключите сервер

1. Из домашней сети откройте адрес вашего роутера с портом `8080`. Например, для роутера `192.168.1.1` это `http://192.168.1.1:8080/`.
2. Войдите **учётной записью роутера с правами управления**, например admin. Если на роутере уже зарегистрирован KeenDNS или CrazeDNS, снаружи используйте `https://brolight.ДОМЕН-РОУТЕРА/`. При задержке появления внешнего адреса начните с локального.
3. На **Главной** в разделе **Xray** нажмите **Проверить обновление**, затем **Установить**. Дождитесь появления версии ядра.
4. На вкладке **Серверы** вставьте ссылку сервера и добавьте его. Если у вас ссылка на подписку, откройте **Подписки**, добавьте её и нажмите **Обновить**. Вернитесь на вкладку **Серверы**.
5. У нужного сервера нажмите **Проверить**, затем **Активировать**. На **Главной** проверьте, что отображается выбранный сервер и состояние **Подключено**. Для назначения прокси устройствам по политикам откройте раздел **Keenetic** на Главной. [Руководство по WebUI](USER-GUIDE-GO.md)

## Переход с shell Light 1.x/2.0

1. Сохраните на компьютере ссылки серверов, адреса подписок, порядок, исключения и параметры резервирования. Если хотите сохранить копию конфигурации, скопируйте каталоги `/opt/broray-light/config`, `/opt/broray-light/servers` и `/opt/broray-light/subscriptions`. Храните копию в закрытом месте.
2. Удалите прежний Light по инструкции к вашей версии. Если Keenetic сообщает, что старый интерфейс используется, сначала уберите его из соответствующей политики и повторите штатную очистку. Entware сохраните. [Руководство Light 2.0](https://github.com/BROadmin/BROray-Light/blob/v2.0.0/docs/beginner-installation.md)
3. Установите 3.5.10 по [шагам выше](#install). Добавьте сохранённые ссылки и подписки, восстановите порядок и исключения, затем активируйте сервер.

Установщик проверяет наличие полного BROray и старого Light. При таком конфликте он останавливается и сообщает причину.

## Обновления и восстановление

На уже установленной Go-версии откройте **Главная → BROray-Light → Проверить обновление**. Если есть новый выпуск, нажмите **Обновить**. Light проверяет подпись манифеста, размер и SHA-256 архива.

Для проверки службы из Entware используется `/opt/broray-light/bin/broray-light ready --version 3.5.10`. Для повтора незавершённой установки или отката есть команда `/opt/broray-light/bin/broray-light recover`. Журнал службы находится в `/tmp/broray-light/run/daemon.log`.

## Ручное скачивание и совместимость

Выполните `opkg print-architecture`, если хотите скачать архив вручную. Для бинарника ARMv7 нужна поддержка VFPv3.

| Архитектура пакетов Entware | Архив Linux |
| --- | --- |
| `aarch64-3.10` | [ARM64](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/broray-light-3.5.10-linux-arm64.tar.gz) |
| `armv7-3.2` | [ARMv7](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/broray-light-3.5.10-linux-armv7.tar.gz) |
| `mipsel-3.4` | [MIPSEL](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/broray-light-3.5.10-linux-mipsel.tar.gz) |
| `mips-3.4` | [MIPS](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/broray-light-3.5.10-linux-mips.tar.gz) |

Сверьте SHA-256 архива перед распаковкой в отдельный каталог внутри `/tmp`. Для команды `./broray-light install --sha256` возьмите SHA-256 **извлечённого бинарника** для своей архитектуры. [Контрольные суммы архивов](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/SHA256SUMS) · [Контрольные суммы бинарников](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/SHA256SUMS.binaries)

### Совместимость ядра на MIPS

Бинарники Light для MIPS и MIPSEL используют `softfloat`. Официальные архивы Xray 26.11.9 для этих архитектур используют `hardfloat` и требуют поддержки со стороны устройства. Проверка на физическом роутере выполнена на ARM64. Для остальных архитектур проверены сборки. [Проверки](VALIDATION-GO.md)

## Статистика установок и обновлений

Light отправляет событие после подтверждённой установки или обновления. В нём версия, ревизия, вид операции, архитектура и идентификатор события. Если прошивка предоставляет сведения об устройстве, добавляются короткий код модели и хеш серийного номера с отдельным префиксом Light. Исходный серийный номер, домен, пароли и настройки не отправляются. Чтобы отказаться от статистики, добавьте к строке `"$work/broray-light" install --sha256 "$binary_sha"` в блоке установки флаг `--no-install-statistics` или используйте его при ручном запуске установщика. [Данные и контракт приёмника](UPSTREAM-GO.md)
