# BROray-Light 2.0.0

Отдельный лёгкий VLESS-клиент для Keenetic с Entware **aarch64-3.10**. Публичная версия и версия OPKG — **2.0.0**; технический идентификатор обновителя — `2.0.0-r1`.

## Что нового

- Выбор официальной версии Xray и переустановка текущей. Предварительная версия, непроверенный архив и понижение ядра требуют отдельных подтверждений.
- Точный архив Xray 26.2.6 заблокирован по отрицательному тесту Light; статус совместимости полного BROray не переносится автоматически.
- Исправлены владение одинаковыми серверами при пересечении подписок, сохранение их идентификаторов, порядка и исключений автопереключения.
- Избирательно перенесены применимые исправления из проверенного BROray 3.1.0-r09c02: процессы Xray, операции ядра, подписки, имя интерфейса и навигация. Light не пересобран из полного продукта.
- Операционные файлы и загрузки находятся в защищённой RAM. Исправлено наследование временного каталога установщика фоновой службой, из-за которого мог появляться ложный статус ошибки интерфейса.

Сохранены native-вход Keenetic, защита сессий, fail-closed владение, подпись обновлений, атомарное переключение и откат. Routes, управление DNS-over-TLS, рейтинги и история качества не добавлялись.

## Установка и обновление

- [Пошаговая инструкция на GitHub](https://github.com/BROadmin/BROray-Light/blob/main/docs/beginner-installation.md): Entware, SSH, установка с SHA-256, первый вход, подписки, серверы, резервное переключение и диагностика.
- [Документация на сайте](https://docs.brovibe.cloud/broray-light/).
- [История версий](https://github.com/BROadmin/BROray-Light/blob/main/CHANGELOG.md).

Для установленного проверенного `1.0.0-r1`: **Главная → BROray-Light → Проверить обновление → Обновить**. Не устанавливайте чистый IPK поверх существующей установки. Обновление приложения сохраняет настройки, серверы, подписки и установленный Xray. Равная версия — успешный no-op, понижение Light запрещено.

Для чистой установки используйте проверяемый блок из инструкции. SHA-256 установщика: `d7d1a709621f3154c0f5b5892a98bddd3f3f782b57d01eb15025e739abcd44f2`.

## Размер и ограничения проверки

Постоянно около **35 МиБ вместе с Xray**. Собственный app-slot Light: **146 файлов, 858363 байта**. Рекомендуемые 80 МиБ свободного `/opt` — запас для безопасной атомарной замены ядра, не размер Light. Временные операции используют RAM `/tmp`; ориентир 64 МиБ свободно, предпочтительно 128 МиБ. Не обходите динамическую проверку места.

Чистая установка содержит **Xray 26.9.9 — upstream prerelease**. На авторизованном ARM64-роутере шесть версий прошли текущий VLESS/XHTTP/REALITY-профиль; у 26.2.6 зафиксирована первая внешняя HTTPS-ошибка. Это не гарантия всех сочетаний транспорта, сервера и моделей роутеров.

## Проверки и контрольные суммы

Независимые Build A/B побайтово совпали: **8 из 8 файлов**. Индекс подписан существующим ключом. Выполнены Linux-регрессия в dash/BusyBox, 22 сценария Chromium, чистая установка, переход с r1 в изолированной среде, equal-version, downgrade refusal, rollback и persistence; на тестовом роутере — точный пакет, штатный вход, работающие серверы, переустановка Xray, подпись, запрет понижения, перезапуск и сохранность данных.

В assets приложены `SHA256SUMS`, `RELEASE-MANIFEST.json`, `INPUT-MANIFEST.json`, `REPRODUCIBILITY.json`, `ACCEPTANCE.json`, `release.json` и `release.json.minisig`. Исходник проверенных сборок: `f4af30d98fd1f227e5116def825c09399437086f`. Предыдущие релизы не перезаписываются.
