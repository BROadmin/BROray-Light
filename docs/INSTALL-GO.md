# Установка BROray-Light 3.5.10 и переход с прежнего Light

## Подготовка

Нужны поддерживаемый Keenetic или Netcraze с Entware, локальный доступ к WebUI и SSH. Выполните `opkg print-architecture` и выберите архив.

| Архитектура пакетов Entware | Архив |
| --- | --- |
| `aarch64-3.10` | `broray-light-3.5.10-linux-arm64.tar.gz` |
| `armv7-3.2` | `broray-light-3.5.10-linux-armv7.tar.gz` |
| `mipsel-3.4` | `broray-light-3.5.10-linux-mipsel.tar.gz` |
| `mips-3.4` | `broray-light-3.5.10-linux-mips.tar.gz` |

Скачайте архив, SHA256SUMS и SHA256SUMS.binaries из одного выпуска. [Релиз GitHub](https://github.com/BROadmin/BROray-Light/releases/tag/v3.5.10) · [SHA256SUMS](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/SHA256SUMS) · [SHA256SUMS.binaries](https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10/SHA256SUMS.binaries) На компьютере вычислите SHA-256 архива и сравните со строкой для вашей архитектуры. Скопируйте проверенный архив на роутер в RAM. Для бинарника ARMv7 нужна поддержка VFPv3. Для распаковки и установки временно требуется место и под архив, и под извлечённый бинарник.


Выполняйте установку от root. Установщик требует, чтобы `/opt/etc/init.d` был обычным каталогом, принадлежал эффективному UID установщика и не разрешал запись группе или остальным. Используйте доверенный том Entware. Если права или владелец не соответствуют требованиям, установка останавливается с сообщением `unsafe directory /opt/etc/init.d`. Для постоянной установки подготовьте Entware на доверенном томе, доступном только администратору. Сценарий приёмки в RAM не подходит для постоянной установки.

## Чистая установка

1. Подключитесь к роутеру по SSH. В отдельной папке внутри `/tmp` распакуйте архив командой `tar -xzf ИМЯ_АРХИВА`.
2. Возьмите SHA-256 бинарника вашей архитектуры из `SHA256SUMS.binaries`. Запустите `./broray-light install --sha256 ШЕСТНАДЦАТЕРИЧНЫЙ_SHA256`. Установщик проверит содержимое, запустит `S24broray-light` и дождётся готовности.
3. Откройте `http://LAN-IP:8080/` из домашней сети или `https://brolight.ДОМЕН-KEENDNS/` при зарегистрированном домене роутера. Войдите учётной записью Keenetic с правами управления. Бинарник находится в `/opt/broray-light/bin/broray-light`, постоянные данные в `/opt/broray-light/state`.
4. На Главной откройте «Xray» и установите закреплённую версию. На «Серверах» импортируйте ссылку, проверьте и активируйте профиль. Добавленные подписки при необходимости обновите вручную. [Руководство по WebUI](USER-GUIDE-GO.md)
5. На Главной включите управление интерфейсом Keenetic, если он нужен вашим политикам. Выберите созданный Light proxy в Keenetic самостоятельно. При наличии внешних ссылок отключение интерфейса сохранит квитанцию для повтора. После снятия ссылок через Keenetic нажмите «Повторить очистку».

Установщик откажет при обнаружении полного BROray или старой службы Light. Сущности, которыми управляет другой продукт или сам роутер, ему не передаются автоматически. Пароли Keenetic хранятся только в запросе авторизации. Ссылки подписок и серверные ключи являются частью приватного состояния.

## Удалённый доступ через KeenDNS / CrazeDNS

При установке Light запускает WebUI на порту `8080` в домашней сети и автоматически настраивает публикацию `brolight` через зарегистрированный домен KeenDNS или CrazeDNS. Оба способа доступа включены по умолчанию. Внешний адрес имеет вид `https://brolight.ДОМЕН-KEENDNS/`.

Если сервис доменных имён ещё запускается или домен пока отсутствует, WebUI доступен по локальному адресу, а Light проверяет готовность публикации при работе службы. Если имя `brolight` занято правилом, созданным вручную или другой установкой, Light оставляет его владельцу и сохраняет локальный доступ. Откройте внешний адрес из другой сети, чтобы проверить работу облака. [Руководство Netcraze по внешнему доступу](https://support.netcraze.ru/titan-se/nc-4210/ru/15884-remote-access-to-home-network-resources-with-dns.html)

## Переход с shell Light 1.x/2.0

1. Скопируйте на компьютер `/opt/broray-light/config`, `/opt/broray-light/servers` и `/opt/broray-light/subscriptions`. Отдельно сохраните исходные ссылки серверов и подписок, порядок, исключения, имя активного сервера и параметры резервирования. Защитите копию от общего доступа.
2. Выполните штатное удаление **старой** версии по её руководству. Убедитесь, что старый updater и служба остановлены, а Light больше не владеет прежним интерфейсом. При предупреждении о чужом или используемом интерфейсе сначала разберитесь с его владельцем в Keenetic. [Руководство shell Light](beginner-installation.md)
3. Установите Go-версию по шагам выше. Импортируйте сохранённые серверные ссылки, создайте подписки, обновите их и восстановите порядок, исключения и резервирование. Скопированные shell-каталоги служат резервной копией для возврата к старому выпуску. Go-версия использует отдельную схему состояния.

## Обновления и восстановление

Главная → «BROray-Light» → «Проверить обновление» → «Обновить». Обновитель Go-версии использует подписанный манифест `light-go-release.json` с действительным сроком. Если доступна более новая версия, Light проверяет размер и SHA-256 архива перед установкой. Подписанный канал shell-версии обслуживает прежние shell-выпуски. Для перехода на Go выполните ручной перенос по шагам выше.

Для проверки службы используется `/opt/broray-light/bin/broray-light ready --version 3.5.10`. При выбранном сервере команда требует активный процесс, ответ через SOCKS и подтверждение принадлежащего Light интерфейса, если управление включено. Для повтора незавершённой установки или отката используется `/opt/broray-light/bin/broray-light recover`. Журнал службы располагается в `/tmp/broray-light/run/daemon.log`.

## Статистика установок и обновлений

Как и полный BROray, Light отправляет на `https://stat.brovibe.cloud/v1/install-events` отдельное событие после подтверждённой установки или обновления. В запрос входят случайный идентификатор события, вид операции, версия, ревизия и архитектура. Если прошивка предоставляет сведения об устройстве, добавляются короткий код модели и SHA-256 серийного номера с отдельным префиксом Light. Исходный серийный номер, домен, конфигурация, пароли и настройки сети остаются на роутере.

При временном сбое сети служба повторяет отправку с тем же идентификатором до шести дней с первой попытки после синхронизации часов. Откаты и повторная установка той же сборки не создают события. Обновление со сборки без сведений о ревизии не записывается как новая установка. Для установки и последующих обновлений без статистики добавьте к команде `install` флаг `--no-install-statistics`. Запуск WebUI и проверка готовности не зависят от доступности приёмника.

## Совместимость ядра на MIPS

Бинарники BROray-Light для MIPS и MIPSEL собраны с `GOMIPS=softfloat`. У официальных MIPS/MIPSEL ZIP Xray `26.11.9` метаданные Go показывают `GOMIPS=hardfloat`. Для них нужна поддержка соответствующих инструкций в процессоре или прошивке. Установщик ядра исполняет проверенный кандидат перед заменой действующего бинарника. Для устройства без такой поддержки потребуется совместимая отдельная сборка Xray. [Выпуск Xray 26.11.9](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9)
