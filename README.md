# BROray-Light

Лёгкая отдельная редакция BROray для маршрутизаторов Keenetic: только VLESS, понятный WebUI и безопасное управление Xray без функций маршрутизации полного BROray.

## Возможности и ограничения

BROray-Light предназначен для одного понятного сценария: подключение Keenetic через VLESS-серверы Xray.

- три страницы WebUI: **Главная**, **Серверы**, **Подписки**;
- ручное добавление VLESS-ссылок;
- импорт VLESS-серверов из подписок;
- имя для каждой подписки;
- ручное и автоматическое обновление подписок;
- устранение дублей по параметрам VLESS, в том числе между ручным добавлением и несколькими подписками;
- проверка, активация и изменение порядка серверов;
- детерминированное автопереключение после заданного числа ошибок;
- управление выделенным proxy-интерфейсом Keenetic;
- установка, обновление и переустановка текущей версии Xray;
- подписанные Stable-обновления BROray-Light с запретом downgrade и автоматическим rollback.

В Light намеренно отсутствуют Routes, управление DNS-over-TLS, рейтинги, история качества, плановое измерение качества и протоколы кроме VLESS. BROray-Light — отдельный продукт, а не режим полного BROray; их совместное активное владение одним Keenetic блокируется по принципу fail-closed.

## Требования

Перед установкой проверьте:

- маршрутизатор Keenetic с установленным Entware;
- архитектуру Entware `aarch64-3.10`;
- рабочий доступ в интернет с маршрутизатора;
- SSH-доступ с правами `root`;
- не менее 100 МБ свободного места в `/opt` для пакета, Xray, обновления и предыдущего рабочего слота;
- отсутствие установленного полного BROray в `/opt/broray`.

Команды предварительной проверки:

```sh
opkg print-architecture
df -h /opt
test ! -e /opt/broray && test ! -e /opt/etc/init.d/S24broray && echo "Конфликтов нет"
```

Если полный BROray обнаружен, не удаляйте его файлы вручную и не продолжайте установку Light, пока не выбран один продукт.

## Установка

Ниже приведена установка Stable `1.0.0-r2`. Выполняйте команды в SSH-сессии Keenetic от `root`.

```sh
opkg update
cd /tmp
curl -fL https://github.com/BROadmin/BROray-Light/releases/download/v1.0.0-r2/SHA256SUMS -o BROray-Light-SHA256SUMS
curl -fL https://github.com/BROadmin/BROray-Light/releases/download/v1.0.0-r2/broray-light-install-1.0.0-r2.sh -o broray-light-install-1.0.0-r2.sh
grep 'broray-light-install-1.0.0-r2.sh$' BROray-Light-SHA256SUMS | sha256sum -c -
chmod 700 broray-light-install-1.0.0-r2.sh
/opt/bin/ash ./broray-light-install-1.0.0-r2.sh
```

Установщик:

1. требует запуск от `root`;
2. прекращает работу при обнаружении полного BROray;
3. загружает пакет только по HTTPS;
4. проверяет точный размер и SHA-256 пакета;
5. устанавливает зависимости через `opkg`;
6. разворачивает проверенный Xray в `/opt/broray-light/runtime/xray`;
7. запускает `S23broray-light-updater` и `S24broray-light`;
8. публикует WebUI через отдельный объект KeenDNS `brolight`, если его ownership можно доказать однозначно.

После установки проверьте:

```sh
/opt/etc/init.d/S23broray-light-updater status && echo "Updater: OK"
/opt/etc/init.d/S24broray-light status && echo "BROray-Light: OK"
/opt/broray-light/runtime/xray version
/opt/bin/broray-light-web-publishctl status
```

## Вход в WebUI

В локальной сети откройте:

```text
http://IP-АДРЕС-KEENETIC:8080/
```

Если на Keenetic настроен KeenDNS и публикация прошла успешно, внешний адрес имеет вид:

```text
https://brolight.ВАШЕ-ИМЯ.keenetic.link/
```

Используются логин и пароль учётной записи Keenetic. BROray-Light не хранит пароль: проверка выполняется средствами KeeneticOS. Не публикуйте порт `8080` напрямую в интернет и не отключайте встроенную защиту сессии.

## Первоначальная настройка

1. Откройте **Подписки**, задайте понятное название, вставьте HTTPS-ссылку и нажмите **Добавить подписку**. Если подписки нет, добавьте одну VLESS-ссылку на странице **Серверы**.
2. На странице **Серверы** нажмите **Проверить** у нужного узла, затем **Активировать**.
3. Вернитесь на **Главную**. В карточке Keenetic нажмите **Настроить** или **Исправить** и затем **Обновить статус**.
4. Убедитесь, что активный сервер указан по имени, соединение работает, интерфейс Keenetic имеет статус **Активен**, а Xray запущен.
5. При необходимости задайте порядок и включите автопереключение на странице **Серверы**.

## Главная

Главная страница показывает итоговое состояние системы:

- **Активный сервер** — имя, внутренний идентификатор и результат соединения;
- **Автопереключение** — включено ли оно и чем завершилась последняя автоматическая проверка;
- **Keenetic** — точное имя управляемого интерфейса и статус `Активен`, `Не активен`, `Требует внимания` или `Ошибка`;
- **Xray** — установленная версия, состояние процесса и доступность обновления/переустановки;
- **BROray-Light** — версия, Stable-канал и доступность обновления.

Статус **Ожидание первой проверки** у автопереключения не является ошибкой: настройки сохранены, но плановая проверка ещё не выполнялась. **Выключено** означает, что автоматические проверки не запускаются.

## Серверы

### Ручное добавление

Вставьте полную ссылку `vless://…` и нажмите **Добавить сервер**. Другие протоколы отклоняются. Название узла берётся из подписи ссылки; параметры подключения сохраняются локально на Keenetic.

### Действия с сервером

- стрелки **↑/↓** меняют порядок проверки;
- **Проверить** запускает проверку конкретного сервера;
- **Активировать** делает сервер текущим и применяет конфигурацию Xray;
- **Удалить** удаляет неактивный сервер.

Активный сервер удалить нельзя. Сначала активируйте другой сервер. Это защищает работающую конфигурацию от неявного разрыва.

### Дубли

После ручного импорта, создания/обновления подписки и планового обновления выполняется дедупликация. Сравниваются нормализованные параметры VLESS и стабильный ключ импорта. При пересечении сохраняется активный сервер; затем приоритет имеет ручная запись, после неё — одна стабильная запись подписки. Перед удалением дублей создаётся резервная копия.

## Подписки

### Добавление и имя

В поле **Название** укажите любое понятное имя, например `Основная`, `Работа` или `Резерв`. В поле **Ссылка подписки** вставьте HTTPS-адрес и нажмите **Добавить подписку**. URL хранится как секрет и не отображается в списке. Импортируются только корректные VLESS-записи.

### Ручное обновление

Кнопка **Обновить** загружает подписку немедленно, синхронизирует её серверы и удаляет дубли. Ошибка загрузки не должна уничтожать предыдущий рабочий набор.

### Автообновление

В карточке подписки:

1. включите **Автообновление**;
2. задайте интервал от 5 до 10080 минут;
3. нажмите **Сохранить автообновление**;
4. проверьте отображаемое время следующего запуска.

Планировщик работает внутри основного сервиса BROray-Light. При занятой глобальной операции запуск безопасно пропускается, а не выполняется параллельно с другой мутацией.

### Удаление

Кнопка **Удалить** удаляет подписку и принадлежащие ей серверы после подтверждения. Если сервер этой подписки активен, удаление будет отклонено. Активируйте узел из другой подписки или ручной узел и повторите удаление.

## Автопереключение серверов

На странице **Серверы** задаются:

- включение автоматических проверок;
- число последовательных ошибок до переключения — от 1 до 10;
- пауза после переключения в секундах;
- порядок серверов стрелками **↑/↓**.

Алгоритм проверяет кандидатов сверху вниз и выбирает первый подходящий сервер. Рейтинги и история качества не используются. Возможные состояния на Главной:

| Состояние | Значение |
| --- | --- |
| Выключено | Автоматические проверки не выполняются |
| Ожидание первой проверки | Настройки сохранены, первый цикл ещё не запускался |
| Сервер работает | Последняя проверка успешна, счётчик ошибок сброшен |
| Обнаружены ошибки | Порог ещё не достигнут |
| Сервер переключён | Выбран следующий доступный сервер |
| Нет доступной замены | Порог достигнут, но рабочий кандидат не найден |

## Обновление и переустановка

### Xray

На Главной нажмите **Проверить обновление** в карточке Xray. Если доступна новая версия, кнопка предложит обновление. Если установлена актуальная версия и временного места достаточно, доступна **Переустановка** той же версии. Бинарный файл проверяется до замены; при ошибке рабочий runtime сохраняется.

### BROray-Light

В карточке BROray-Light нажмите **Проверить обновление**. Обновление принимается только из подписанного Stable-индекса. Updater проверяет подпись, размер, SHA-256 и безопасные пути архива, запрещает downgrade, атомарно переключает app-slot и откатывается на предыдущий рабочий слот при ошибке health-check. Равная версия возвращает успешный `no-op`.

Проверка из SSH:

```sh
/opt/bin/broray-light-updaterctl check
/opt/bin/broray-light-updaterctl status
```

## Диагностика

Начните с этих команд:

```sh
/opt/etc/init.d/S23broray-light-updater status
/opt/etc/init.d/S24broray-light status
/opt/broray-light/runtime/xray version
/opt/bin/broray-light-updaterctl check
/opt/bin/broray-light-web-publishctl status
tail -n 100 /opt/broray-light/logs/broray-lightd.log
```

Типовые действия:

- WebUI не открывается по локальному адресу — проверьте `S24broray-light`, порт `8080` и адрес LAN Keenetic;
- внешний адрес не открывается — проверьте KeenDNS и `/opt/bin/broray-light-web-publishctl status`;
- возвращается форма входа — войдите учётной записью Keenetic, не отключая cookies;
- сервер не активируется — сначала нажмите **Проверить**, проверьте VLESS-параметры и сообщение WebUI;
- подписка не удаляется — её сервер активен; активируйте другой сервер;
- обновление не предлагается — установленная версия равна последней Stable или новее неё;
- интерфейс Keenetic требует внимания — нажмите **Исправить**, затем **Обновить статус**.

При сообщении об ошибке приложите версию BROray-Light, версию Xray, точный текст ошибки и обезличенный фрагмент журнала. Не публикуйте VLESS-ссылки, URL подписок, пароли, cookies и токены.

## Резервная копия и сохранность данных

Обновление app-slot сохраняет пользовательские настройки, серверы, подписки и Xray runtime. Перед ручным обслуживанием можно создать архив:

```sh
tar -czf /tmp/broray-light-backup.tgz -C /opt/broray-light config servers subscriptions
sha256sum /tmp/broray-light-backup.tgz
```

Скопируйте архив с маршрутизатора и храните его как секрет: он содержит параметры серверов и URL подписок.

## Удаление

Обычное удаление пакета останавливает сервисы, но намеренно сохраняет пользовательские данные, Xray и конфигурацию Keenetic:

```sh
opkg remove broray-light
```

Перед полным удалением, пока пакет ещё установлен, безопасно снимите только принадлежащую Light Web-публикацию:

```sh
/opt/bin/broray-light-web-publishctl delete
opkg remove broray-light
```

Управляемый proxy-интерфейс данных удаляйте отдельно в интерфейсе Keenetic только после отключения BROray-Light. Продукт не создаёт и не управляет Routes.

Чтобы необратимо стереть сохранённые настройки после резервного копирования и удаления пакета, удаляйте только эти точные каталоги — не `/opt` целиком:

```sh
rm -rf /opt/broray-light
rm -rf /opt/var/lib/broray-light /opt/var/lib/broray-light-updater
rm -rf /opt/var/lock/broray-light /opt/var/lock/broray-light-updater
```

## Безопасность

- вход и сессия защищаются нативной проверкой KeeneticOS;
- URL подписки и VLESS-параметры считайте секретами;
- Stable-индекс подписан minisign, а архивы проверяются по размеру и SHA-256;
- неоднозначное совместное владение с полным BROray блокируется;
- изменения слота выполняются атомарно с health-check и rollback;
- не отключайте TLS для внешнего доступа и не публикуйте LAN-порт напрямую.
