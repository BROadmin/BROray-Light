# Матрица VLESS и чтение подписок

Источник правил для `vless://` v3.5.10 — рабочий парсер полного BROray из дерева `92dc010ebad5fd21dff9e625925e9847b3714640`. Перенесены разбор, нормализация, проверка контекста параметров и построение Xray stream settings. [Код донора](https://github.com/BROadmin/BROray/tree/92dc010ebad5fd21dff9e625925e9847b3714640/areas/servers)

## Транспорт и защита

| Транспорт URI | none | TLS | REALITY |
| --- | --- | --- | --- |
| RAW, включая TCP и отсутствие type | Да | Да | Да |
| WS или websocket | Да | Да | — |
| gRPC | Да | Да | Да |
| HTTPUpgrade или httpUpgrade | Да | Да | — |
| XHTTP или splithttp | Да | Да | Да |
| mKCP | Да | Да | — |

- Поддерживаемые режимы XHTTP — `auto`, `packet-up`, `stream-up`, `stream-one`. У gRPC допустимы режим по умолчанию, `gun` и `multi`, оба написания `serviceName` и согласованные `host` и `authority`.
- Оба варианта Vision требуют TLS или REALITY. При `encryption=none` им нужен RAW. Для поддерживаемых вариантов `mlkem768x25519plus` действуют правила шифрования и допустимой пары транспорта и защиты.
- Проверяются TLS SNI, ALPN, ECH, pin и имена проверки сертификата, поля REALITY и ML-DSA, RAW-заголовки, параметры mKCP, XHTTP extra и вложенные настройки, `streamOptions` и `finalmask`. Дубли, конфликты, неизвестные параметры и неоднозначный вложенный JSON отклоняются. Метаданные `support-x25519mlkem768` сохраняют предупреждение донора.
- Матрица относится к ссылкам `vless://`. Полные конфигурации Xray JSON и Clash YAML образуют отдельные форматы импорта.

Проверки выполняются на трёх уровнях. Тесты `vless_matrix_test.go` проверяют выбор сочетаний, алиасы, значения полей и отрицательные случаи. Проверки с `BRORAY_XRAY_BIN` передают сгенерированные конфиги закреплённому Xray. Xray 26.11.9 требует шифрования для нечастного IP-адреса, записанного литералом. Сквозной smoke передаёт трафик через локальную цепочку VLESS RAW.

## Подписки

Light загружает подписку по HTTP(S), сохраняет путь и параметры URL и принимает текст UTF‑8 либо стандартный или URL-safe Base64 с заполнением либо без. Учитываются BOM, пустые строки и комментарии. Дубли сворачиваются по итоговой конфигурации Xray. При неоднозначном или некорректном ответе сохраняется последний принятый список. Явный `[]` подтверждает пустой список, в том числе в Base64.

Успешное обновление снимает источник у исчезнувших записей. Удаление подписки снимает её источник со всех записей. Сервер удаляется, когда у него не остаётся источников или ручного владения. Если исчез активный сервер, Light прекращает использовать его и проверяет оставшиеся в прежнем порядке с переходом к началу списка. Новые записи проверяются после прежних. При отсутствии работающей замены Xray остаётся остановлен.

Старая версия Light могла не сохранить расширенные параметры VLESS. При обычном запуске используется прежняя записанная конфигурация. При повторном импорте или успешном обновлении подписки однозначное совпадение исходной ссылки позволяет восстановить параметры с прежним ID и пользовательским именем. Операция сохраняет принадлежность записи и не объединяет профили с разными настройками.

На странице «Серверы» команда «Удалить все, кроме активного» очищает список после подтверждения и сохраняет активную запись. Подписки остаются доступными. Их очередное обновление может снова добавить серверы, которые предоставляет источник.
